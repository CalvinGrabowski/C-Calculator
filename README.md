# C-Calculator

A simple command-line calculator implemented in C++ as a personal project based on the ENGR 103 final project.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Supports integer and decimal calculations
- Demonstrates structured C++ programming and I/O handling

## Skills Learned
- C++ syntax and control flow
- Command-line input/output
- Writing modular and reusable code
